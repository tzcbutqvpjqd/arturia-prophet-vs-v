## Overview

Arturia Prophet VS V recreates the groundbreaking Sequential Prophet VS vector synthesizer, featuring its unique four-oscillator joystick vector mixing and digital wavetable oscillators.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Prophet-VS V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Vector Mixing** | Joystick-controlled blend of four oscillator positions in real time |
| **Wavetable OSCs** | Digital wavetable oscillators with the original VS waveform library |
| **Joystick Automation** | Record joystick movements for evolving vector mix automation |
| **Filter** | Curtis low-pass filter adding analog warmth to the digital oscillators |
